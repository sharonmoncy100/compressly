What is a "passport size photo"?

In India, "passport size photo" is used as a general term for a small, formal ID-style photo or studio photo - not only for an actual passport application. It's the same phrase people use when a photo is needed for an exam admit card, a job application form, a school or college admission form, or a government ID. This passport size photo compressor and Passport Photo Maker works for all of these - you don't need to be applying for a passport to use it.

Tips for exam, job and passport-style photos

  • Use simple filenames without spaces.
  • Check clarity and sharpness after compression - a heavily compressed photo can look blurry right at the KB limit.
  • Avoid screenshots or scanned photos - upload the original photo file for the cleanest result.
  • Avoid white or very light-colored clothing, since it can blend into a white background.
  • Applying for an actual passport? Remove glasses first - the current rules don't permit them, even with a valid prescription. Most exam and job forms are more flexible about this.

FAQ

Is a "passport size photo" the same as an actual passport application photo?

Not necessarily. In India the term is used generally for any small, formal photo - exam admit cards, job applications and school forms all ask for a "passport size photo" without meaning an actual passport application. This tool works for all of them.

Does DPI matter?

DPI is usually ignored by portals. File size, dimensions and clarity matter more.

My photo meets the KB limit but is still rejected.

The form may require a specific background or framing. Use the Passport Photo Maker's automatic background removal and cropping to fix both at once, not just the file size.

Is my photo uploaded to a server?

Resizing and compression happen entirely in your browser. If you use the automatic background removal feature, that part of the image is sent securely to our server to run the background-removal model, and the result is sent back to your browser.

I need this for an actual Indian passport application - where do the exact rules apply?

Passport applications have their own strict specification, including a February 2026 rule change and a no-glasses rule. See our dedicated passport application guide for the full, current requirements.
